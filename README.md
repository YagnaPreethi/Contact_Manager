
# Contact Manager - Python Mini Project

## Project Overview
Contact Manager is a command-line Python application that
allows users to manage contact information.

## Features
- Add new contacts
- View all contacts
- Search contacts by name, phone, or email
- Update existing contacts
- Delete contacts
- Store contact data in a JSON file
- Validate user input and handle errors
- Run automated unit tests

## Technologies Used
- Python
- JSON
- File Handling
- Exception Handling
- unittest
- Git and GitHub

## Project Structure
- app.py: Main application
- test_app.py: Unit tests
- contacts.json: Stored contact data (created automatically)
- README.md: Project documentation

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Run: python app.py

## How to Run Tests
Run: python -m unittest -v

## Learning Outcomes
Practised Python functions, lists, dictionaries, file handling,
exception handling, unit testing, and version control.
